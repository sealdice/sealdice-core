# 应用壳、页面宽度与备份页设计

## 日期

2026-08-10

## 背景

当前 `default`、`wide`、`workspace` 三种路由布局分别挂载一个 `AppShell`。在不同布局间导航时，应用壳会被销毁并重建，导致安全提示的本地去重状态、默认登录和其他壳层初始化逻辑重复执行。

同时，`default` 模式虽然被定义为阅读型后台页面，但没有真正实现居中最大宽度；多个扩展和设置页面又使用了全宽布局，短文本和表单在宽屏上显得偏左。备份页则用两个并排卡片表达两个一级任务，与基本设置的 Tab 信息架构不一致。

## 目标

- 同一次页面运行期间，未设置密码的安全提示只显示一次。
- 刷新浏览器后，如果仍未设置密码，则重新显示安全提示。
- 路由在 `default`、`wide`、`workspace` 间切换时复用同一个 `AppShell` 实例。
- 阅读型后台页采用与自定义文案一致的 1180px 居中内容列。
- 真正需要工作区空间的页面继续使用全宽或固定高度工作区。
- 备份页改为“备份设置”和“备份文件”两个线型 Tab，不再并排展示两个卡片。

## 非目标

- 不持久化用户已经关闭安全提示的状态。
- 不改变后端安全检查和认证 API。
- 不重做各业务页面内部的表格、编辑器或表单。
- 不改变公骰设置和指令测试等明确需要现有布局的页面。

## 应用壳设计

`App.vue` 负责稳定挂载一个非 Plain 页面共用的 `AppShell`。路由元信息只转换为 `contentMode` 和 `containerMode` 属性，不再通过不同 Layout 组件重复创建应用壳。

安全弹窗作为全局反馈组件放在路由内容之外、Naive UI Provider 之内，因此路由切换不会重建它。默认登录初始化也提升到应用根层，只在应用启动时执行一次。认证 token 继续由现有 Pinia auth store 管理；弹窗显示状态只属于单个应用运行期，不新增持久化 Pinia 状态。

Plain 页面仍使用独立布局，不包含侧边栏应用壳。

## 页面宽度语义

- `default`：最大宽度 1180px、水平居中，适合阅读、设置、普通列表和表单。
- `wide`：占满可用内容区，适合确实需要横向空间的复杂表格或大型组合视图。
- `workspace`：在 `wide` 基础上提供工作区最小高度，适合自定义回复和指令测试。

扩展功能中，牌堆、包管理、跑团日志、JS、帮助文档和拦截管理切换到 `default`；自定义回复保留 `workspace`。

综合设置中，基本设置、群组管理、黑白名单、高级设置和改造后的备份页使用 `default`；公骰设置保持现状。

## 备份页设计

`backup.vue` 继续负责查询、Mutation、未保存状态和对话框编排，并新增当前 Tab 的局部 UI 状态。

页面结构为：

1. 页面标题和错误提示。
2. 线型 `n-tabs`，包含“备份设置”和“备份文件”。
3. “备份设置”复用 `BackupConfigPanel`，负责表单和保存命令。
4. “备份文件”复用 `BackupFileList`，负责文件表格和备份、下载、删除命令。
5. 执行备份与批量删除对话框仍由页面统一挂载。

`BackupConfigPanel` 和 `BackupFileList` 的根节点从 `n-card` 改为无卡片嵌套的语义化 `section`，保留现有 props 和 emits 合约。

## 组件边界

- `App.vue`：全局 Provider、稳定应用壳、Plain 分支和应用级初始化。
- `AppShell.vue`：侧边栏、面包屑、搜索和未保存提示，不再拥有全局认证初始化。
- `AppUnlockDialog.vue`：登录和单次运行期安全检查，不随业务路由切换销毁。
- `appShellLayout.ts`：路由布局到壳层模式的纯函数映射。
- `backup.vue`：备份领域的页面编排与 Tab 状态。
- `BackupConfigPanel.vue`：备份配置表单。
- `BackupFileList.vue`：备份文件列表和列表操作。

## 错误处理与状态

- 安全检查失败沿用现有请求错误行为，不把失败误判为“未设置密码”。
- token 被清空后，安全检查的本地状态重置；重新登录后可再次检查。
- 关闭安全提示只影响当前页面运行期；刷新会创建新实例并重新检查。
- 备份查询和操作错误继续使用现有页面级 Alert、Message 和 Dialog。

## 验证

按用户要求不新增或运行自动化测试。实现后运行前端类型检查、构建和静态差异检查，并人工核对路由元信息与组件挂载层级。

## 风险

- 稳定应用壳会让侧边栏折叠、搜索懒加载和高级设置点击计数在普通路由间保持，这是修复重复初始化后的预期行为。
- 原本依赖 `workspace` 最小高度的页面改为居中模式后，需要确认其内部组件没有隐式依赖父级 flex 高度。
- 备份面板移除 Card 外框后，需要保持标题、操作区和内容之间的层级与移动端换行。
