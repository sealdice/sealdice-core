# 连接配置表单

这里只支持内置协议实际使用的文本（0）、整数（1）、布尔值（10）和下拉选项（12）。
定义位于 `forms.json`，通过 `go:embed` 随二进制发布，不从工作目录加载。

创建、连接测试与编辑接口统一提交以 `field_name` 为键的配置对象。
`BuildParamsByConfig` 一次遍历完成默认值、必填、类型、整数范围与选项校验，
只将声明过的字段交给适配器。没有数字 ID 提交、远程选项或通用表单注册机制。

`minimum` / `maximum` 用于实际端口字段，服务端与前端控件共用。
定义只读，编辑接口复制字段后才放宽敏感字段的必填约束。
留空敏感字段保持原值；普通可选文本的清空由编辑接口处理。
