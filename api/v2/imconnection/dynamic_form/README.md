# 连接配置表单

此包只描述内置连接协议实际使用的四种字段：文本（0）、整数（1）、
布尔值（10）和下拉选项（12）。协议定义保存在 `forms.json`，由
`go:embed` 随二进制发布，不读取工作目录，也没有运行时注册或远程选项提供器。

HTTP 创建、连接测试与编辑接口统一提交以 `field_name` 为键的配置对象。
`BuildParamsByConfig` 在一次遍历中完成默认值、必填、类型与选项校验，
只将声明过的字段交给适配器。字段 ID 仅用于展示，不再提供按 ID 提交的第二条转换链。

读取到的定义只读；编辑接口先复制字段再放宽敏感字段的必填要求。
空敏感字段保持原值，普通可选文本的清空语义由编辑接口处理。

响应 DTO 暂时保留原有元数据字段，保持现有 OpenAPI 与前端生成类型兼容；
这些字段不意味着支持日期、多选或动态加载等未使用的能力。
